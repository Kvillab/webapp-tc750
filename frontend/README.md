# TC-750 - Defendsa de la educación pública desde la perspectiva de la educación pública popular

Este proyecto es un sitio web no-oficial del Trabajo Comunal Universitario (TCU) TC-750 de la Universidad de Costa Rica, dedicado a la defensa de la educación pública desde la perspectiva de la educación pública popular.

## Descripción del Proyecto

Este proyecto consiste en el desarrollo del sitio web oficial del TC-750, cuyo objetivo principal es:

> "Promover la defensa de la educación pública como derecho humano fundamental desde un enfoque de educación popular, mediante procesos de formación, investigación y acción social."

El sitio web sirve como:

- Plataforma de difusión de las actividades del TCU
- Herramienta de comunicación con la comunidad universitaria y la sociedad en general
- Repositorio de materiales educativos y recursos relacionados con la defensa de la educación pública

## Instalación y Configuración

Sigue con pasos para configurar el proyecto localmente:

### Requisitos Previos

- Node.js
- npm o yarn
- Git

### Pasos de Instalación

1. Clonar el repositorio:

  ```bash
  git clone https://github.com/tu-usuario-de-git/tcu-project.git
  cd tcu-project
  ```

2. Instalar dependencias:

  ```bash
  npm install
  ```

3. Configurar variables de entorno (cuando hayan):

  Esto se tiene que realizar en el archivo ".env", este no se sube al repositorio.

4. Iniciar el servidor de desarrollo:

  ```bash
  npm run dev
  ```

5. Abrir en el navegador:

  ```bash
  http://localhost:5173
  ```
